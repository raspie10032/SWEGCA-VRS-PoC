# SWEGCA VRS judgment reference components

This is a separately exportable **component-code package under preparation**, not a finished product or a complete empirical reproduction package. It contains the actual memory activation, VRS intervention and source-provenance decision implementation used by the research code, plus its existing constructed-fixture tests. The source modules are exported byte-for-byte from the upstream commit recorded in `LINEAGE.json`; they are not a newly invented simplified decision algorithm.

The primary scientific question is whether VRS changes judgment, not whether it improves accuracy. The historical integrated Q study observed one changed memory-branch output and two unchanged outputs. An earlier P8C task observed zero changes in twelve A/B choices. Those different tasks are not pooled. The two historical 100-source analogy evaluations do not constitute 100 isolated VRS interventions. These statements describe existing evidence, not results generated by this package's synthetic tests.

## Run locally without the original checkout

Use Python 3.11 or later. The first validated environment is Python 3.14.7 and pytest 9.1.1; other versions are not yet verified. The four component modules and analyzer use only the Python standard library. Tests additionally require pytest. From the extracted package root:

```sh
python verify_package.py
python -m pip install -r requirements-test.txt
python -m pytest -q
```

If pytest is already installed, skip the installation step. No GPU, model, service, network, media or original repository is required to run these **software diagnostics**. Do not treat six constructed experience records as six real observed episodes, the fixture's projection as a learned full-current resident graph, or a test PASS as scientific confirmation. The package does not connect to a live main process.

`test_vrs_strength_changes_the_actual_reevidence_and_decision_path` executes the existing five-arm engine; `test_existing_causal_engine_uses_hot_consumer_in_all_arms` connects it to the actual provenance-based decision consumer. The memory tests cover failed/negative/uncertain/conflicting/pending records, snapshot replacement, conflicts, detached input and authority boundaries. Test counts are not new experience counts.

One upstream test, `test_integrated_read_only_handler_emits_source_receipts_and_rejects_writes`, is explicitly deselected in `pyproject.toml`: it imports the full resident service, which is not exported in this component package. Its original source is retained unchanged so the exclusion is inspectable. This is not an integration-test PASS. Run that test in the full upstream environment; bringing that service and its dependencies into an independently reproducible package remains separate work.

## Analyze authorized saved receipts

```sh
python tools/analyze_rozephine_vrs_judgment_influence.py /path/to/authorized/report.json
```

The input must contain the historical `raw_units` receipt schema. This reads a supplied report only; it does not query a model or rerun the experiment. It retains all directed changes, unchanged units and invalid controls, and separates correctness from influence. No private raw report or fabricated replacement for one is bundled. Do not replace historical failed gates with the analyzer's post-hoc interpretation.

## Runtime and authority boundary

The main process owns identity, persistent cognition, full experience and VRS generations. `HotCausalAblationEngine` accepts a main-owned immutable memory/VRS pair, hot current/frozen strength indices and transient evidence/decision callbacks. All diagnostic arms share Deja vu, Recall and Replay and vary promotion at Re-evidence. No-VRS mechanically disables promotion; a difference from this arm alone does not isolate learned relation content. Frozen projection is a run-level diagnostic, not a permanent memory freeze. Cohorts and archive file selection are not cognition allowlists.

`HotSourceProvenance` preserves source attribution and abstains on unresolved conflicts. It produces a bounded branch decision, not a final semantic commit. Replaceable 135.5M/E2B/other specialists remain proposal producers; the component package does not transfer main ownership to them. World/action/persistent-write/model-update/distribution/P3 authority is not granted by these outputs.

## What is still outside this package

This package therefore makes progress on runnable-code delivery but **does not complete the paper or its empirical-reproduction requirement**. Do not launch the retired R v1 plan.
